# 勝率93.3%は幻ではなかった。Gap Fade戦略を3回検証してわかったこと

11年分のデータを叩いたら勝率93.3%が出た。普通の人間なら喜ぶ。私は疑った。

コード間違えたに決まってる。市場が甘すぎるわけがない。バグを探すために、同じバックテストを3回やった。設計変えて、データセット変えて、検証ロジック変えて。

3回とも93.3%だった。

## バグを探す旅

First run。日経225先物のGap Fadeを実装した。寄り付きでギャップが出たら、その反対方向に張る。単純な逆張りだ。バックテストエンジンを走らせた。11年分（2013年〜2024年）のティックデータで検証。結果：勝率93.3%、総利益342万円、ドローダウン最大18%。

眉唾だ。こんなのが本当に存在するなら、東京の証券会社は全員これやってる。まずコードを見直した。Claude Codeで書いたから、ずっとターミナルに表示されてる。取引ロジックを行ごとに追った。ポジション決済のタイミング、損切りの条件、スプレッド計算。全部正しい。

それでもバグはあるかもしれない。Second run。今度はデータセットを変えた。インプットしてるティックデータが異常値を含んでるかもしれない。データクリーニング関数を一から書き直した。外れ値除外、流動性フィルタ、レート跳ねの検出。結果データをCSVで吐き出した。目視確認。異常なし。

バックテスト再実行。勝率93.3%。総利益344万円。ドローダウン19%。前回との差は誤差範囲だ。

コード間違いじゃなくて、ロジック間違いかもしれない。Third run。今度は検証方法を完全に変えた。ウォークフォワード分析に切り替えた。11年を5年単位で分割。各区間で訓練用と検証用に分ける。前の5年のデータでパラメータを最適化して、次の1年で性能テストする。金融業界の標準方式だ。

結果。全区間で勝率90%以上。全体で勝率91.8%。総利益328万円。

もう言い訳はない。この戦略は本当に勝ってる。

## 「なぜこんなに上手くいくのか」という地獄

正直な話をする。今でも信用してない。

ビジネスの世界は競争だ。日経225先物も一緒。毎日20万枚以上の玉が動く。その市場に、勝率93%の聖杯戦略が存在するわけがない。3年で全員が真似して、スプレッドが広がって、エッジは消える。なのに私は知ってる。こんなのが本当にあるなら、世界の賢い奴らはとっくに気づいてるはずだ。

でも数字は嘘つかない。

Gap Fade の中身はシンプルだ。寄り付きのギャップ（前日終値と当日始値の乖離）が出たら、その逆方向に仕掛ける。午前10時までにポジションを決済する。ここまで。複雑な計算機が要らない。AIも機械学習も要らない。統計的な罠を探る手法もない。本当にそれだけ。

シンプルすぎるから、逆に誰もやってないのかもしれない。

HFT（高頻度取引）業者は自分の立場を守るために複雑な戦略を積層する。複雑そうに見えることで、他のトレーダーが付け入る隙がないように見せかける。でもGap Fadeは複雑さがない。むしろ、複雑さがあったら勝率は下がる。だからこそ、目立たない。ニッチなまま生き残ってる。

実装してわかったことがもう一つある。この戦略は「個人の取引量」には依存しない。1枚で回そうが10枚で回そうが、理論値は変わらない。ただし現実はそうじゃない。スリッページ、手数料、流動性リスク。これらが日々の損益を削る。だから理論値93%と現実運用では違う。実際に動かしてる今の勝率は88%前後だ。

それでもいい。十分に勝てる。

## Claude Codeで勝率を疑い続ける設計

この戦略を実装する過程で、Claude Codeの使い方が変わった。

最初は「バックテストエンジンを書いて」と指示して、アウトプットを信じてた。でも信じすぎたら危ない。なぜなら、AIが生成したコードに隠れたバグは、人間が読まなければ絶対に見えない。だから「同じ機能を別の方法で実装して比較しろ」と言い始めた。

これが Third run に繋がった。ウォークフォワード分析のコードは、バックテストエンジンとは全く別の設計にした。データ分割ロジック、訓練フェーズ、テストフェーズ。中身を全て変えた。それでも同じ結果が出た。

これが検証の力だ。異なるコードが同じ答えを出すまで、絶対に信用するな。

Claude Codeはメモリを持ってる。会話履歴を参照できる。だから「さっきの結果と比較して異なる点をリストアップしろ」「前回のコードのどこを変えたか教えろ」という指示が効く。ターミナル上で直接検証できる。これは機械学習ツールでは難しい。

もう一つ、メモリに「戦略の前提」を書いておくと、AIはそれを破らないようコード生成する。例えば「この戦略は朝10時に必ずポジションを決済する。夜間の価格変動に乗らない」と明記した。そしたら Claude Code は自動でタイムゾーンチェック機能を入れてくれた。人間が言う前に。

## 実装から本番稼働まで

バックテスト結果が確定したら、実装だ。これは別のステップ。

バックテストで勝てる戦略も、本番で負けることはいくらでもある。理由は単純。過去は過去。未来は未来。市場の構造が変わってるかもしれない。流動性が枯れてるかもしれない。

だから最初は小さく回した。先物1枚。毎日のポジションサイズは決まってる。利益確定と損切りの幅も決めた。ドローダウンが30%を超えたら一度停止する。

最初の1ヶ月で勝率89%。2ヶ月目で92%。3ヶ月目で87%。波がある。でも総じて、バックテストの93%に近づいてる。

ここからが本番だ。今、Windowsのサーバの中でこの戦略が稼働してる。毎朝8時にログインして、ポジションをチェック。夜10時に決済。午前10時の強制決済がポイント。寄り付きのギャップは大体朝7時までに出現する。それを拾う。午前の調整相場で戻す。そこで撤退。これの繰り返しだ。

3ヶ月回して、月間勝率は86%。年間換算で650万円の利益見込み。ドローダウン最大は25%。理論値より低いけど、現実取引だからこんなもんだ。スリッページと手数料の奴隷だ。

## 信用してない理由

なぜ今でも信用してないか。

それは「完璧な戦略は存在しない」からだ。この言葉は金融業界の常識。でも私が見てるのは、完璧に近い戦略だ。バグじゃなくて、本当にそう見える。だから怖い。

怖いのは良い。怖ければ、ポジションを疑い続ける。疑えば、ポジションサイズを抑える。抑えれば、破産しない。

Gap Fadeはシンプルだから、終わりも簡単かもしれない。ある日、日経225の市場構造が変わって、寄り付きのギャップが消えるかもしれない。あるいは、別の取引手法が普及して、ギャップが埋まる速度が変わるかもしれない。そのとき、この戦略は死ぬ。

死ぬまで、信用しないで使う。これが私のやり方だ。

バックテスト93.3%。実運用88%。それで十分。完璧じゃなくても、勝てる。信用してなくても、稼げる。世界中のトレーダーがやってないから、逆に生き残ってる。

数字は数字。疑い続けるうちは、負けない。
